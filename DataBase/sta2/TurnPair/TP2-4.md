1. **Turns** — одна или две одиночные стрелки (`TurnSolo`).
2. **addr_CV** — переключения пары стрелок через сервер (виртуальный CAN-Bus пакет).
3. **state_SV** — базовый адрес трёх кнопок управления: Auto = `state_SV`, C = `state_SV + 1`, T = `state_SV + 2`.
4. **FB_C_C** — индикатор прямого положения стрелки (виртуальный CAN-Bus пакет).
5. **FB_Lost_CV** — индикатор обратной связи об ошибке стрелки (виртуальный CAN-Bus пакет).
6. **FB_T_C** — индикатор бокового положения стрелки (виртуальный CAN-Bus пакет).
